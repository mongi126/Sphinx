# Extract numeric X/Y coordinate matrix from a data frame

Extract numeric X/Y coordinate matrix from a data frame

## Usage

``` r
.extract_xy_matrix(df, x_col = NULL, y_col = NULL)
```

## Arguments

  - df:
    
    data.frame/data.table

  - x\_col:
    
    optional explicit X column name

  - y\_col:
    
    optional explicit Y column name

## Value

numeric matrix with columns X and Y
