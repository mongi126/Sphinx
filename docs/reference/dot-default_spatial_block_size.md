# Default spatial block size for pseudo-replication-aware DE

Default spatial block size for pseudo-replication-aware DE

## Usage

``` r
.default_spatial_block_size(x, y, target_cells_per_block = 40)
```

## Arguments

  - x, y:
    
    numeric coordinate vectors

  - target\_cells\_per\_block:
    
    approximate cells per block (default: 40)

## Value

numeric block side length
