# Default search radius from local spacing (median 1-NN x multiplier)

Default search radius from local spacing (median 1-NN x multiplier)

## Usage

``` r
.default_search_radius(mean_nn_dist, multiplier = 3)
```

## Arguments

  - mean\_nn\_dist:
    
    local spacing distance

  - multiplier:
    
    scale factor (default: 3 \~ a few cell spacings)

## Value

numeric search radius
