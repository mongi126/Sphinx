# Resolve X/Y coordinate column names

Resolve X/Y coordinate column names

## Usage

``` r
.resolve_xy_cols(df, x_col = NULL, y_col = NULL)
```

## Arguments

  - df:
    
    data.frame/data.table

  - x\_col:
    
    optional explicit X column name

  - y\_col:
    
    optional explicit Y column name

## Value

named character vector c(x = ..., y = ...)
